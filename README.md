# Seller Image & Price Helper

A production-oriented, mobile-first React + TypeScript + Tailwind seller toolkit.

## What works immediately

- JPG/JPEG/PNG/WEBP upload with 10 MB validation.
- Client-side image normalization/compression while preserving the uploaded image in app state.
- Five Demo Mode catalog layouts generated from the original image — no API key required and never mislabeled as AI.
- Download individual images or all generated images.
- Product details stored in localStorage.
- Actual, volumetric and chargeable-weight estimates.
- Marketplace-neutral shipping category estimate; no Meesho scraping or hard-coded Meesho charges.
- Selling price calculator with marketplace fee, GST, cost, profit and psychological price suggestions.
- Clear-project confirmation and graceful error toasts.
- Responsive desktop/mobile layout.
- Optional secure server proxy for an authorized AI image provider.

## Requirements

Node.js 20+ recommended.

## Setup

```bash
npm install
cp .env.example .env
npm run build
npm run start
```

The production server listens on `PORT` (default `8787`) and serves `dist`.

For development:

```bash
npm run dev
```

This runs Vite on 5173 and the API server on 8787.

## Demo Mode

Demo Mode requires no API key. Upload a product and press **Generate Images**. The app uses Canvas to build five professional-looking catalog templates around the original product photo. It does not claim those images were generated by AI.

## AI integration

Secrets must stay server-side. Never expose `AI_IMAGE_API_KEY` as a `VITE_*` variable.

Set:

```env
AI_IMAGE_API_URL=https://your-authorized-image-provider.example/api/generate
AI_IMAGE_API_KEY=your-server-side-key
AI_IMAGE_MODEL=your-image-model
AI_IMAGE_TIMEOUT_MS=60000
```

The included backend sends a marketplace-safe prompt plus the uploaded image data URL to the configured provider. The provider endpoint must be one you are authorized to use and must accept this JSON contract. The generic proxy expects a response containing `data[0].url` or `data[0].b64_json`. If your provider uses a different contract (for example multipart image input), adapt only `server/index.js` rather than exposing credentials in the browser.

Important: the current generic integration requests one AI image per call. A production provider-specific adapter can issue five calls with five distinct prompts (white background, studio, lifestyle, model/wearer where appropriate, and 45-degree composition) and return all five. Keep provider terms and user consent in mind.

## Shipping estimate

Volumetric weight uses the standard planning divisor of 5000: `L × W × H / 5000` in kg. Chargeable weight is the larger of actual weight (kg) and volumetric weight. This is an estimate only; marketplace-specific rules can differ.

## Price formula

The calculator treats marketplace fee and GST as percentages of selling price:

`required price = (product + packaging + other costs + shipping + desired profit) / (1 - marketplace% - GST%)`

If fee percentage + GST percentage is 100% or more, the calculator safely returns a zero required price rather than dividing by zero.

## Security

- API key is server-side only.
- JSON request size is limited.
- Image payload is validated before forwarding.
- User inputs are length-limited where relevant.
- No unnecessary personal data is sent to the AI endpoint.
- Images are not uploaded to a server in Demo Mode.
